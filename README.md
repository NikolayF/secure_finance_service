# Secure Finance Service

## Описание

Это веб-приложение которое позволяет делать безопасные переводы с банковских карт. Приложение использует модель машинного обучения, обученную на анонимном наборе данных, для безопасности утечек конфиденциальной информации.

## Технологии

*   FastAPI (Python)
*   Nginx (Web proxy)
*   PostgreSQL (база данных)
*   RabbitMQ (для асинхронной обработки задач)
*   Docker (контейнеризация)


## Запуск приложения (с использованием Docker Compose)

1.  **Установите Docker и Docker Compose.**
2.  **Склонируйте репозиторий (если ещё не склонировали).**
3.  **Перейдите в корневую директорию проекта.**
4.  **Создайте файл `.env` в корне и заполните его необходимыми переменными окружения.** (пример содержимого в файле .env_template).

5.  **Запустите приложение:**

    ```bash
    docker-compose up --build
    ```

    *   Флаг `--build` необходим для пересборки образов, если были внесены изменения в коде или Dockerfile.
    *   Для запуска в фоновом режиме используйте флаг `-d`: `docker-compose up -d --build`.

6.  **Доступ к приложению:** Откройте браузер и перейдите по адресу `http://localhost:85` (или на другой порт, настроенный в `nginx/nginx.conf`).  Адрес, который использует приложение, зависит от настроек nginx.

## Тестирование

*   Используется `pytest` для тестирования.
*   Тесты находятся в каталоге `tests/`.
*   Для запуска тестов выполните команду:

    ```bash
    pytest "название_файла_с_тестами"
    ```
